# ignite-lockfile-demo

Demo for Microsoft Ignite BRK286 ("Secure the CI pipeline: Practical defenses for GitHub Actions").

Two identical workflows. `with-lockfile.yml` is onboarded to
[`.github/workflows/actions.lock`](.github/workflows/actions.lock), generated by
[`gh actions-lock`](https://github.com/github/gh-actions-lock).
`without-lockfile.yml` is not.

- **Moved tag:** [`nodeselector/ignite-greet-action`](https://github.com/nodeselector/ignite-greet-action) `v1.0.0` gets moved to new code.
- **Imposter commit:** a pull request "pins" `actions/checkout` to a SHA that exists only in a fork.

All "malicious" code only prints a message.
